# AGENTS.md

## Absolute Rules

1. **Read the specs first.**
   Before doing any work, read `SYSTEM_SPEC.md`, `IMPLEMENTATION_SPEC.md`, and `RUN_LOG_SPEC.md`.

2. **Do only the requested phase.**
   Never continue into the next phase unless explicitly instructed.

3. **ORC is the educational source of truth.**
   Do not substitute generic web knowledge for the school's curriculum or assessment requirements.

4. **Never fabricate source material.**
   Missing, inaccessible, ambiguous, or unreadable material must be recorded as unresolved.

5. **Never alter raw sources.**
   Original papers, memoranda, and curriculum files must remain preserved and unchanged.

6. **Every derived knowledge item must have provenance.**
   It must be traceable back to the source material that supports it.

7. **Separate fact from inference.**
   Never present an AI-derived interpretation as an official curriculum or marking requirement.

8. **Do not invent assessment requirements.**
   When a memo or rubric exists, use it as the primary evidence for what is assessed.

9. **Do not silently change the knowledge bank.**
   Validated knowledge is versioned and immutable. Changes require a new version.

10. **Log important decisions and failures.**
    Every significant analytical decision, unresolved issue, and execution failure must be recorded according to `RUN_LOG_SPEC.md`.

11. **Never mix curriculum truth with student state.**
    The knowledge bank describes what is required. The student model describes what the student understands.

12. **Stop when the phase is complete.**
    Validate the work, write the required logs and status, report the result, and stop.
